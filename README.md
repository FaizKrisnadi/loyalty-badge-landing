# Loyalty Badge Landing Page

Static HTML landing page for your loyalty badge.

## Files
- `index.html`: Main page
- `assets/loyalty-badge.png`: Badge artwork
- `assets/partner-icon.png`: Avatar image (replaces the `PL` icon)

## Local preview
```bash
cd /Users/faizkrisnadi/loyalty-badge-landing
python3 -m http.server 8080
```
Then open `http://localhost:8080`.

## Deployment
You can deploy this as a static site to your domain using your preferred host (Cloudflare Pages, Vercel, Netlify, or your existing server).
